Outbox

Wipe Outbox

Delete all pending outbox events and partitions. Use this to recover operationally, e.g. after wiping the catalog while outbox events referencing it are still queued. This operation cannot be undone.

Confirm Outbox Wipe

This will permanently delete all pending outbox events and partitions. Type yes to confirm.
