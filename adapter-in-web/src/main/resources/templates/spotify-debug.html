Spotify Debug

Manually trigger the individual requests the backend performs against the Spotify Web API and inspect the raw JSON result. This is a read-only debugging tool — nothing is persisted and no further processing happens with the result. Requests use your own valid Spotify access token and hit the real Spotify Web API.
